## Problem

자연수 n이 주어졌을 때, GCD(n, k) = 1을 만족하는 자연수 1 ≤ k ≤ n 의 개수를 구하는 프로그램을 작성하시오.

## Input

첫째 줄에 자연수 n (1 ≤ n ≤ 10<sup>12</sup>)이 주어진다.

## Output

GCD(n, k) = 1을 만족하는 자연수 1 ≤ k ≤ n 의 개수를 출력한다.

## Sample Input 1

```text
1
```

## Sample Output 1

```text
1
```

## Sample Input 2

```text
5
```

## Sample Output 2

```text
4
```

## Sample Input 3

```text
10
```

## Sample Output 3

```text
4
```

## Sample Input 4

```text
45
```

## Sample Output 4

```text
24
```

## Sample Input 5

```text
99
```

## Sample Output 5

```text
60
```
