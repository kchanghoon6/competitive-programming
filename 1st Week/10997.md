## Problem

예제를 보고 규칙을 유추한 뒤에 별을 찍어 보세요.

## Input

첫째 줄에 N(1 ≤ N ≤ 100)이 주어진다.

## Output

첫째 줄부터 차례대로 별을 출력한다.

## Sample Input 1

```text
1
```

## Sample Output 1

```text
*
```

* * *
*   *
*****
