## Problem

정수 N이 주어졌을 때, 소인수분해하는 프로그램을 작성하시오.

## Input

첫째 줄에 정수 N (1 ≤ N ≤ 10,000,000)이 주어진다.

## Output

N의 소인수분해 결과를 한 줄에 하나씩 오름차순으로 출력한다. N이 1인 경우 아무것도 출력하지 않는다.

## Sample Input 1

```text
72
```

## Sample Output 1

```text
2
2
2
3
3
```

## Sample Input 2

```text
3
```

## Sample Output 2

```text
3
```

## Sample Input 3

```text
6
```

## Sample Output 3

```text
2
3
```

## Sample Input 4

```text
2
```

## Sample Output 4

```text
2
```

## Sample Input 5

```text
9991
```

## Sample Output 5

```text
97
103
```
